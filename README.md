# Olympus App Store

A private-curated Umbrel Community App Store for self-hosted apps.

## Add to Umbrel

Add this repository as a Community App Store in umbrelOS:

`https://github.com/Jojje84/zeus-community-app-store`

## Apps

- **SparkyFitness** — health, nutrition and workout tracking
- **Lyftr** — lightweight workout and nutrition tracking

## Updates

A scheduled GitHub Actions workflow checks the upstream GitHub releases every day. When a newer release exists, it prepares a pull request in this repository instead of updating installed apps automatically.

That means updates are reviewable before they become available in Umbrel.
