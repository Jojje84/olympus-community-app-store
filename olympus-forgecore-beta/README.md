# ForgeCore Beta

Clean-user ForgeCore 0.1.0-beta.59 for Umbrel.

- Umbrel app ID: `olympus-forgecore-beta`
- Port: `8800`
- External storage: dedicated `ForgeCore-Beta` root
- First run: create a ForgeCore account, then add apps, destinations and runners yourself
- No previous ForgeCore apps, jobs, audit history, connections or runner identities are imported
- Primary dashboard areas: Overview, Apps, Runners, System, Logs & Activity, and About
- Jobs, Releases and Delivery are grouped under Apps; Settings and health are grouped under System
- About remains a direct primary navigation item
- Dashboard remains mobile-adapted with dedicated narrow-layout regression coverage
- Source-only folders such as `tests/`, `docs/`, `scripts/` and `config/` remain in ForgeCore but are not shipped as Store payload
