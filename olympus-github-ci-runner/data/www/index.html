GitHub CI Runner

The Olympus CI package is installed.

To register this runner with a repository, open GitHub → Settings → Actions → Runners → New self-hosted runner and copy the short-lived registration token.

Then SSH into Umbrel and run:

bash ~/umbrel/app-data/olympus-github-ci-runner/data/configure.sh

Restart the app after configuration. The runner uses labels such as beelink and unicore-build.

The CI Docker engine is isolated from Umbrel's host Docker socket. Only trusted repositories and trusted workflow code should be allowed to use this runner.
